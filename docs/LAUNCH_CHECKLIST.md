# KICKDEX MVP Launch Checklist

Use this as the launch board. Keep it honest: checked means shipped, tested, and deployed.

## Blockers

- [ ] Real edge detection generated from data, not hardcoded hero demo.
- [ ] `docs/data/edges.json` generated by `scripts/build_data.py`.
- [ ] Landing Edge Number reads from `edges.json`.
- [ ] Inicio fixture cards show estimated edge where available.
- [ ] `tests/test_edge.py` covers edge math and invalid odds.
- [ ] `docs/og.png` exists and returns `200` in production.
- [ ] Legal owner fields completed in `aviso-legal.html`.
- [ ] Public stack decision documented: static-only or Streamlit as internal admin.

## Honesty and Trust

- [ ] `/coverage.html` documents actual league/data coverage.
- [ ] `/methodology.html` explains Poisson, edge calculation, sources, and limitations.
- [ ] Landing copy no longer implies live odds until live odds exist.
- [ ] Player stats UI clearly states season aggregate coverage.
- [ ] Referee UI clearly states aggregate/source limitations.
- [ ] Footer links legal, privacy, cookies, terms, methodology, and coverage.

## Static Launch Polish

- [ ] `robots.txt` added.
- [ ] `sitemap.xml` added.
- [ ] `README.md` reflects current static-first architecture.
- [ ] Open Graph preview verified on production URL.
- [ ] Mobile layout checked on Inicio, Comparador, Jugadores, Arbitros, H2H.
- [ ] Lighthouse or equivalent pass reviewed.

## Data Health

- [ ] Daily workflow green.
- [ ] Player coverage check green.
- [ ] Referee coverage check green.
- [ ] Calendar feed has upcoming fixtures.
- [ ] Build preserves previous good JSON when scrapers fail.
- [ ] Data status visible to users.

## Nice After MVP

- [ ] TheOddsAPI live odds adapter behind same `edges.json` UI contract.
- [ ] Twitter/X bot for daily top edges.
- [ ] Weekly "The Edge Brief" newsletter.
- [ ] Match Report export linked from Comparador.
- [ ] Split large `h2h.json` for faster mobile loading.
