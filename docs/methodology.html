Metodologia

KICKDEX es una herramienta informativa. Sus probabilidades son estimaciones matematicas basadas en datos historicos y no son garantias, picks ni recomendaciones de apuesta.

Probabilidades

El comparador usa forma reciente local/visitante, goles a favor, goles en contra, over 2.5, BTTS e historial H2H cuando existe muestra suficiente. Con esos datos estima probabilidades 1X2 mediante un modelo Poisson con ajuste Dixon-Coles para marcadores bajos.

Edge

El edge se calcula como: probabilidad del modelo menos probabilidad implicita de la cuota. La probabilidad implicita de una cuota decimal es 1 / cuota. Por ejemplo, si el modelo estima 55% y la cuota implica 50%, el edge mostrado es +5.0 puntos porcentuales.

Cuando existen cuotas Bet365 en football-data.co.uk, KICKDEX usa columnas de cierre B365CH/B365CD/B365CA; si no estan disponibles usa B365H/B365D/B365A. Si el feed no trae cuotas futuras, el hero muestra el mejor edge historico reciente y lo etiqueta como historico.

Control de calidad

El pipeline evita usar el propio partido para calcular la forma: cada edge se calcula con partidos anteriores a la fecha analizada. Tambien se excluyen muestras demasiado pequenas y outliers extremos para que la superficie publica no dependa de una lectura estadistica fragil.

Aviso de riesgo

Los edges son estimaciones. Una cuota puede moverse, un modelo puede equivocarse y una ventaja estadistica no implica resultado. KICKDEX no gestiona apuestas, no enlaza casas de apuestas y no promete rentabilidad.
